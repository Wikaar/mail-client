# MailTabs

Почтовый клиент для Android: каждый ящик — отдельная вкладка, письма разных ящиков никогда не смешиваются.

Стек: Kotlin, Jetpack Compose, Material 3, Room, Jakarta Mail (IMAP/SMTP), Hilt, WorkManager. minSdk 26. Без рекламы и аналитики.

## Что уже есть (этап 1)

- Несколько ящиков вручную (IMAP/SMTP, SSL/STARTTLS), пресеты IONOS и Яндекс.
  Пароли шифруются AES-GCM ключом из Android Keystore.
- Вкладки ящиков (ScrollableTabRow + HorizontalPager) со счётчиком непрочитанных во «Входящих».
- Меню вкладки (долгое нажатие или «⋮»): «Пометить все прочитанными», «Удалить все письма»
  (с подтверждением и количеством; письма уходят в Корзину ящика).
- Боковое меню с папками текущего ящика (IMAP LIST, вложенные, счётчики), создание/переименование/удаление своих папок.
- Список писем: аватар, имя, тема, превью, время, непрочитанные жирным.
  Свайп влево — в Корзину (Snackbar «Отменить»), свайп вправо — прочитано/непрочитано.
  Долгое нажатие — переместить в папку.
- Все действия применяются локально сразу и уходят на сервер через офлайн-очередь (WorkManager).
- Просмотр письма (WebView, внешние картинки по кнопке), вложения в «Загрузки», ответ, ответ всем,
  пересылка (с вложениями), новое письмо с выбором ящика-отправителя.
- Push: foreground-сервис типа `remoteMessaging` (Android 14+) с IMAP IDLE на каждый ящик;
  уведомление с именем ящика открывает нужную вкладку. Плюс периодическая синхронизация раз в 15 минут.

Переключение вкладок свайпом работает от краёв экрана (полосы ~36 dp) и по пустому месту;
горизонтальный свайп по строке письма — действия над письмом.

## Сборка

```
./gradlew assembleDebug
```

GitHub Actions собирает debug APK на каждый push и выкладывает его как artifact `mailtabs-debug-apk`.
